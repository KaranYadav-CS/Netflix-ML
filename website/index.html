    🌟 Auspify ML Internship Program Architecture

    Practical 4-week research & development portfolio designed by Karan Yadav on Netflix's 8,807-title catalog.

    Task 1 NLP & Similarity

    Content Recommendation Engine

    • ▸Core Tech:TF-IDF Vectorizer (10,000 features), Cosine Similarity
    • ▸Input:Weighted Content Soup (genre ×2, cast, director, synopsis)
    • ▸Speed:Sub-millisecond semantic search lookup
    • ▸Validation:Verified on benchmark cross-genre reference queries
    Task 2 Supervised Learning

    Content Type Prediction Model

    • ▸Core Tech:Logistic Regression, Decision Tree, Random Forest
    • ▸Validation:20% stratified holdout with zero duration leakage
    • ▸Metrics:99.7% Accuracy, 0.998 F1-Score, 1.000 ROC-AUC
    • ▸Inference:Real-time REST API serving live probabilities
    Task 4 Unsupervised Learning

    Netflix Catalog Segmentation

    • ▸Core Tech:K-Means, Elbow Method, Silhouette Optimization
    • ▸Projection:2D Principal Component Analysis (41.2% variance)
    • ▸Clusters:5 distinct strategic catalog archetypes discovered
    • ▸Utility:Acquisition roadmap & demographic targeting
    Task 6 Capstone Analytics

    Content Success Analytics Engine

    • ▸Core Tech:5-Fold Stratified CV, KPI Synthesis & Longitudinal BI
    • ▸Predictive:International reach likelihood & format velocity
    • ▸Visuals:Interactive Chart.js executive dashboards
    • ▸Delivery:Machine-readable JSON executive brief
